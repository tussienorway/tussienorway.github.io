agy-smart-kit v2.1

Gjør Antigravity CLI (agy) smart ut av boksen: automatisk capability-discovery (skills, plugins og MCP-servere) + to-stegs prompt-raffinering (Gemini → Claude, med Gemini Neon critic som fallback ved 429 og lokal nøkkelord-ranker hvis helt offline) før hver ikke-trivielle melding.

⬇ Last ned ZIP (agy-smart-kit.zip) ⬇ Last ned TAR.GZ Se repo på GitHub ↗
Krav: agy CLI + Python 3.9+ + Bash Avhengigheter: 0 eksterne pakker Tester: 14 enhetstester + live verify

1. Hva som er laget

agy-smart-kit er en komplett, ferdig pakke som kobler seg på Antigravity CLI sitt PreInvocation-hook-system og gjør hver reelle brukerforespørsel skarpere før hovedagenten begynner å svare.

Steg 1 Lokal triage Hilsener (hei, ok) og rene slash-kommandoer (/help) hoppes over lokalt uten modellkall.
Steg 2 Capability Discovery Skanner globale skills, plugin-skills, innebygde skills, workspace-skills opp til git-rot, plugins og MCP-servere (cached per repo).
Steg 3 Stage 1 → Stage 2 Gemini skriver om forespørselen til en presis spesifikasjon; Claude strammer inn. Ved Claude 429 kjører Gemini Neon critic automatisk.
Steg 4 Sikker injeksjon Injiserer [SMART-PIPELINE v2] via Antigravitys native injectSteps med verifiserte filstier, cache og kretsbryter.

Nøkkelfunksjoner og rettelser i v2.1.0

  • 100 % native Antigravity CLI-protokoll: Bruker riktig --print-timeout 60s (Go-varighet med enhet), leser lastUserInput / conversationId / cwd / workspacePaths, svarer med injectSteps og fletter inn i hooks.json med toppnivå hook-gruppeformat uten å røre andre hooks.
  • Presis discovery & parsing: Støtter flerlags YAML-beskrivelser (description: >-), filtrerer bort innrykkede metadata-linjer fra agy plugin list, ignorerer No MCP servers configured., og cacher katalogen separat per prosjektmappe.
  • Robust feiltoleranse: Kretsbryter (circuit breaker) åpner automatisk etter 3 feil på rad i samme sesjon så agy aldri henger. Degraderte fallback-svar caches ikke, og lokal nøkkelord-ranker støtter norsk (æ, ø, å).
  • Trygg installasjon & avinstallering: Både install.sh og uninstall.sh tar tidsstemplede sikkerhetskopier (.bak-*) av hooks.json og GEMINI.md, og verify.sh kjører 14 automatiserte tester.

2. Hvordan man starter og bruker det

Alternativ A — Klon repo fra GitHub (anbefalt)

git clone https://github.com/tussienorway/agy-smart-kit.git ~/agy-smart-kit
cd ~/agy-smart-kit
bash install.sh

Alternativ B — Last ned ZIP direkte fra tussienorway.github.io

curl -fsSL https://tussienorway.github.io/agy-smart-kit/downloads/agy-smart-kit.zip -o agy-smart-kit.zip
unzip agy-smart-kit.zip -d ~/agy-smart-kit
cd ~/agy-smart-kit
bash install.sh

Start agy på nytt når installatøren avslutter med INSTALL_OK. Hooken kjører da automatisk på alle ikke-trivielle meldinger.

Daglig bruk, feilsøking og avinstallering

# Se status, latens, cache-treff og kretsbryter
python3 ~/.gemini/config/skills/auto-capability-and-prompt-pipeline/scripts/pipeline.py --status

# List alle oppdagede skills, plugins og MCP-servere i gjeldende repo
python3 ~/.gemini/config/skills/auto-capability-and-prompt-pipeline/scripts/pipeline.py --discover

# Kjør manuelt på én konkret oppgave
~/.gemini/config/skills/auto-capability-and-prompt-pipeline/scripts/prepare_task.sh "Lag et CLI-verktøy med tester"

# Kjør full ende-til-ende-test mot ekte agy-modeller
bash verify.sh --live

# Tøm cache etter å ha lagt til nye skills
python3 ~/.gemini/config/skills/auto-capability-and-prompt-pipeline/scripts/pipeline.py --clear-cache

# Avinstaller rent (legg til --purge for å fjerne pipeline.json også)
bash uninstall.sh
