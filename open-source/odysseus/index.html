Problemet: tekstlikhet er ikke identitet

Den deterministiske oppryddingen brukte fuzzy matching og delstrengmatching til å avgjøre om minner var duplikater. Det kan fjerne nyttig informasjon før den valgfrie modellfasen får vurdere den.

Eksempler fra syntetiske regresjonstester
Faktum AFaktum B
User runs 16 local servers.User runs 64 local servers.
User is allergic to peanuts.User is not allergic to peanuts.
Møte med Åse torsdagMøte med Åge torsdag

Den gamle normaliseringen filtrerte også bort mange ikke-ASCII-tegn. Det gjorde enkelte forskjellige navn umulige å skille i sammenligningen.

Rettelsen: konservativ automatisk sletting

Forslaget erstatter usikker likhetsmatching med eksakt tekstsammenligning etter Unicode NFC-normalisering, casefold() og normalisering av whitespace. Eksisterende grenser for eier, kategori og prioritering beholdes; en redundant tekstbasert fallback fjernes.

Dette er en bevisst avveining: noen nærduplikater blir stående lenger. Det er bedre enn at en deterministisk snarvei sletter forskjellige fakta. Den valgfrie AI-fasen kan fortsatt vurdere semantiske duplikater, men denne rettelsen beviser ikke at modellstyrt konsolidering er feilfri.

Bidraget ble utviklet med AI-assistert analyse og automatisert diff-review. Testene ble faktisk kjørt lokalt; automatisert review er ikke menneskelig maintainer-review.

English summary

tussienorway proposed Odysseus PR #6955 to preserve distinct facts during deterministic memory consolidation. Fuzzy similarity and substring matching are replaced with conservative equality after NFC, casefold and whitespace normalization. The change includes regression tests for names, numbers, negation and Unicode.

44 relevant local tests passed. An isolated HTTP runtime check preserved both synthetic facts without model endpoints. These are local results, not full-suite or upstream-CI results. The PR was open and not merged when checked on 28 October 2026.
