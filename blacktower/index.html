Blacktower — SuperGrok OS

Selvhostet multi-agent kontrollplan med Google Vertex AI som hovedhjerne, automatisk nødfailover til vertex_ai/gemini-2.5-flash-lite, plug-and-play agent-harnesses og sanntids RAM- og VRAM-overvåking.

1. Hva som er laget

  • Sentral modell-ruter & Vertex AI-nødløsning: Google Vertex AI (gemini-2.5-pro / gemini-2.5-flash) som primærhjerne, OpenAI/OpenRouter som sekundærpool, og automatisk failover til vertex_ai/gemini-2.5-flash-lite (Global Endpoint) ved 429, 402, 5xx eller budsjettgrense.
  • Orkestrator, Hybrid Minne & Cron: SQLite (WAL-modus), USER.md + per-bot MEMORY.md synkronisert med SQLite FTS5 fulltekstsøk, og vedvarende 5-felts cron-planlegger.
  • Agent-Harnesses: Støtte for antigravity, hermes (selvlærende skills), cloudroom (isolerte git worktree-sandboxes) og codex.
  • OpenClaw Gateway, MCP Hub & HITL-sikkerhet: Signert OpenClaw-webhook, JSON-RPC 2.0 MCP Tool Hub og 3-nivå sikkerhetsport med menneskelig godkjenning før risikable handlinger.
  • Sanntids RAM- & VRAM-telemetri: Nytt endepunkt GET /api/system/resources, CLI-kommando botctl resources, oppstartsbanner i terminalen og live fremdriftsbarer i Web UI-dashboardet (oppdateres hvert 3. sekund).

2. Hvordan man starter og bruker det

Start kontrollplanet og Web UI-dashboardet med ett ord i terminalen:

Blacktower

Dashboardet åpnes på http://127.0.0.1:8787 med sanntids SSE-hendelser, godkjenningskø, minnesøk og live RAM/VRAM-forbruk. Du kan også kjøre CLI-kommandoer direkte:

cd /home/tussie/supergrok-os
./bin/botctl resources          # JSON med live RAM & VRAM
./bin/botctl ask architect "Lag plan for tjeneste X"
./bin/botctl approvals          # Se ventende Tier 3-godkjenninger

3. Valgt Wheel of Time-alias: Blacktower

Aliaset Blacktower (og små bokstaver blacktower) er inspirert av The Black Tower fra Robert Jordans The Wheel of Time — hovedkvarteret og treningssenteret for Asha’man. 

# Registrert i /home/tussie/.bash_aliases
alias Blacktower='cd /home/tussie/supergrok-os && ./bin/botctl serve --host 127.0.0.1 --port 8787'
alias blacktower='Blacktower'
