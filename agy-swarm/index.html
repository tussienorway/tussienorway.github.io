Systemets Grunnlov

Fem ufravikelige arkitekturvalg som forhindrer kontekstforurensning, merge-konflikter og hallusinert suksess.

1. Hermes som Kropp, Gemini 4 som Hjerne

Nous Hermes Agent håndterer varig tilstand, minne, cron-tidsplaner, Telegram-gateways og makro-DAG i Hermes Kanban. Gemini 4 Argon i agy utfører dyp kodebygging i isolerte mapper.

SKILL.md <= 15 KB

2. Hard Worktree & Fotavtrykkslås

Ingen agenter deler mappe. Hver oppgave tildeles et låst git worktree (git worktree add --lock) og må deklarere footprint_files. Kollisjonsfrie bølger kjøres via partition_by_footprint().

Zero File Overlaps

3. Tabula Rasa Blackboard (SQLite WAL)

Rå stdout og git diff lagres på disk i blackboard.sqlite. Hermes mottar kun en validert Pydantic-kvittering (SwarmExecutionReceipt). Kontekstvinduet holdes rent for støy.

get_tail_log(lines=40)

4. SWARM Illusion Delta Guard

Måler avviket mellom lokal suksess og reell integrasjon: Δillusion = Cperceived - Cdistributed. Hvis Δillusion > 0.15, senkes samtidighet automatisk fra 3 til 2 og high thinking påbys.

Circuit Breaker > 0.15

5. Automatisk SFT & DPO Harvester

Modulen harvester.py kobler ~/.gemini/antigravity-cli/ SQLite-sesjoner med verifiserte Blackboard-resultater. Ekstraherer automatiske gullstandard SFT-trajektorier og DPO-preferansepar uten LLM-kostnad.

Auto DSPy / GEPA Evolution

6. Remote Ask-User Bridge

Fanger opp ASK_USER_BLOCK: når krav er tvetydige. Varsler operatør over Telegram og blokkerer oppgaven i Hermes Kanban uten å kaste bort tokens i en blind loop.

Telegram Bot Bridge
